# 模板解析与页面匹配

PPTX 模板是一组承担不同用途的页面与版式。先解析原生结构、渲染全部页面，再识别各类设计，最后为新文稿逐页选择来源页。页面分类由 Agent 结合截图与对象清单判断；`inspect` 提供位置、文字、版式和占位符信息。

## 识别页面用途与样式

查看全部页面的内容、信息密度、标题位置、正文空间、图片与装饰；同时查看所用版式和母版。页面顺序与版式名称可以辅助判断，实际外观和用途决定分类。

| 常见用途 | 识别与复用重点 |
| --- | --- |
| 标题页 / 封面 | 演示主题、大标题、副标题与作者信息；标题占据主要视觉区域，可能带专属横幅或背景 |
| 目录页 | 章节条目、编号和阅读导航；保留目录的信息层级与条目组织方式 |
| 章节过渡页 | 单个章节标题与少量引导文字；用于分隔内容阶段 |
| 内容页 | 正文、图表、流程、比较或数据；通常有明确标题区和充足正文空间，同类可能有单栏、双栏等变体 |
| 结尾页 | 总结、致谢、行动提示或联系方式；保留收尾文字的位置、尺度与留白 |

只记录模板实际提供的类型。空白内容页通过标题、页脚、正文可用区和版式判断，可以在其正文空间中设计新图表与文字。类型无法确定时记录判断依据，查看相近页面及母版后再选用。

将真正跨类型共享的设计与页面专属设计分别记录。共享设计可能包括字体体系、主题色和贯穿各类页面的细线、页码；Logo、横幅或背景只在部分页面出现时，属于相应类型的设计。按模板中的实际分布复用这些元素。

## 记录模板分析与逐页匹配

在任务目录保存 `template-analysis.json`，作为本次制作的设计记录，包含：

- 模板路径、页面尺寸和预览位置。
- 每个候选页的页码、实际用途、样式变体、分类依据、版式引用，以及标题区、正文区、字体配色与专属装饰。
- 全局共享的设计约定。
- 每个新页的页 ID、用途、选中的模板页和样式、参考图路径与选择理由。

例如一份三页模板包含封面、内容和结尾页时，五页文稿可以将第 1 页作为封面来源、第 2 页作为三个正文页的来源、第 3 页作为结尾来源。具体页码与分配根据实际模板和新文稿内容确定。

先匹配用途，再在同类候选中选择适合本页内容的布局。目录、内容和结尾分别使用对应类型；正文有多个变体时，按表格、图表、比较等内容选择。模板缺少所需类型时，以最接近的功能布局为基础设计该页，记录适配依据。例如目录缺失时可以在内容页的标题与正文框架中排列章节条目。

## 将匹配结果用于生成与重建

逐页图像生成请求包含本页用途、选中的模板截图及该类型的布局约定。可以按以下结构写提示词，填入实际分析结果：

```text
页面用途：内容页，展示本页的核心能力与结构图。
参考：选中的内容页截图。
沿用：该页的标题位置、字号层级、主题色、边距、页脚和正文可用区。
本页内容：……
正文安排：在既定正文区域中组织图形与说明。
输出：一张完整的单页视觉稿。
```

生成后先对照同类型模板页，检查标题尺度、标题与正文位置、留白和装饰是否匹配，再检查本页内容。内容页保持正文阅读空间；封面与结尾保持各自的主题和收尾层级。确认后再进行对象重建。

原生 PPTX 制作使用同一个匹配记录：复制所选来源页，或绑定对应版式，然后修改内容。每个目标页分别选择来源，页面专属装饰随其用途复用。既有视觉稿作为补充参考时，也选择相同用途和样式变体的页面。

最终将生成图、实际 PPTX 预览和 SVG 与各自对应的模板页比较，检查用途、布局和装饰。将逐页匹配表与实际检查结果一起交付，便于定位页面采用的设计和后续重新生成。
